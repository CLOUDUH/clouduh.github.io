# 使用路由器连接打印机 Wi-Fi Direct 实现局域网内打印

## Abstract

本文主要解决了如何使用 iKuai 路由器的 Wi-Fi 网卡功能，配置了HP 打印机的 Wi-Fi Direct 中继，从而实现在 iKuai 路由器下的局域网内，直接添加不同网段的打印机，从而实现快捷打印。

## 1 Background

工位屋里有一台直接连接校园网的打印机，LAN 口连接屋里交换机，USB 连接一台老旧 Windows 电脑，开启了 Wi-Fi Director 功能。其他人大多是电脑直接连接屋里交换机，因此可以直接发现打印机从而进行打印。但由于我加了一层路由器，发现不了打印机（且打印机 IP 会变化），只能每次切换 Wi-Fi Director 进行打印，非常麻烦，因此催生了解决这个问题的想法。

### 1.1 拓扑和设备情况

- 打印机型号为 HP LaserJet Pro M405dw，通过 USB 电脑可查看其 LAN 口地址
- 从路由器端和路由器下的设备发起测试，实测 631 和 9100 端口都超时
- USB 电脑通过一个固定 IP 的公用路由器进行上网，已经开放了 SMB 和 LPD 的端口
- 打印机的 Wi-Fi 连接功能和 Wi-Fi Direct 功能不能工作，且校园无线网有 AP 隔离

### 1.2 尝试过的方案

开放公用路由器的 SMB 协议端口和 LPD 端口，LPD 端口能成功下发打印任务，但是会在 windows 7 的电脑上打印任务中名称显示乱码，并且立马显示正在删除，如图。
